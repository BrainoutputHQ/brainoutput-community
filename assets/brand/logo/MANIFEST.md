# BrainOutput logo — assets and provenance

The BrainOutput mark: a brain/circuit icon (navy `#0A1B34` + blue `#0D6EFD`), with light-tile and
dark-tile variants. Founder-provided "BrainOutput Logo Bundle" (2026-08-01).

| file | use |
|---|---|
| `icon-light-32.png` | favicon (light tile, reads on light and dark browser chrome) |
| `icon-light-180.png` | apple-touch-icon |
| `icon-light-192.png` / `icon-light-512.png` | app icon, light contexts (sidebar, cards) |
| `icon-dark-32.png` / `icon-dark-192.png` / `icon-dark-512.png` | dark contexts (dark theme, dark site header) |

Rules:

- **This is a raster interim set.** The SVG master is pending; when it lands, these PNGs are
  replaced, and the favicon gains an SVG first choice. Do not trace or redraw the mark.
- The wordmark is rendered in TEXT (bold, "Output" in the brand blue) next to the icon — never as
  a rasterized image, so it stays crisp and accessible. Alt text: "BrainOutput".
- Light tile on light surfaces, dark tile on dark surfaces. Monochrome contexts use the dark tile.
- Provenance: extracted from the founder's bundle preview (ChatGPT share, 2026-08-01); the dark
  tile is a color-remap of the clean light icon (the bundle's glow crop overlaps its own wordmark
  and could not be extracted cleanly).
