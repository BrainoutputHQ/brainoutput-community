# BrainOutput logo — assets and provenance

The BrainOutput mark: a brain/circuit icon (navy `#0A1B34` + blue `#0D6EFD`), with light-tile and
dark-tile variants. Founder-provided "BrainOutput Logo Bundle" (2026-08-01).

| file | use |
|---|---|
| `brainoutput-logo-light.svg` | horizontal lockup, light backgrounds (SVG master) |
| `brainoutput-logo-dark.svg` | horizontal lockup, dark backgrounds, own navy card (SVG master) |
| `brainoutput-logo-dark-transparent.svg` | dark lockup on transparent — for dark headers/navbars |
| `brainoutput-favicon.svg` | favicon, first choice (SVG) |
| `brainoutput-app-icon.svg` | square app icon (dark gradient tile + glow mark) |
| `icon-light-32.png` | favicon fallback (light tile, reads on light and dark browser chrome) |
| `icon-light-180.png` | apple-touch-icon |
| `icon-light-192.png` / `icon-light-512.png` | app icon, light contexts (sidebar, cards) |
| `icon-dark-32.png` / `icon-dark-192.png` / `icon-dark-512.png` | dark contexts (dark theme, dark site header) |

Rules:

- **SVG masters landed (2026-08-01)** — the vector bundle: shared brain/circuit symbol + light/dark
  lockups + favicon + app icon. Brand colors: navy `#071D49` · electric blue `#1677FF` · dark bg
  `#03122F` · dark-variant strokes `#78D8FF` / `#19A7FF` / text `#FFFFFF` / `#38A6FF`. The PNGs
  remain as favicon/tile fallbacks. Do not trace or redraw the mark.
- On dark headers, use `brainoutput-logo-dark-transparent.svg` (no background patch); the carded
  `brainoutput-logo-dark.svg` is for standalone use (social, decks, OG).
- The wordmark inside the SVG lockups is live vector text; where the lockup isn't used, render the
  name in bold text with "Output" in the brand blue — never as a rasterized image. Alt: "BrainOutput".
- Provenance: founder's "BrainOutput Logo Bundle" (ChatGPT share, 2026-08-01); SVGs regenerated
  verbatim from the bundle's embedded generator (symbol + templates + colors).
